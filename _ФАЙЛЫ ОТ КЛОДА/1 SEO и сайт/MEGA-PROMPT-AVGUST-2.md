# ЧАСТЬ 1 — РАЗМЕТКА PRODUCT/OFFER НА ТУРАХ (самое главное, её физически нет)

## Доказательство проблемы

Я открыл живую страницу `/bali/en/tours/private-car-with-driver-bali` — **JSON-LD со

## 1.1 Что добавить на КАЖДУЮ страницу тура

В `<head>` каждой страницы тура добавь блок:

```html

{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "НАЗВАНИЕ ТУРА КАК НА СТРАНИЦЕ",
  "description": "ОПИСАНИЕ 1-2 ПРЕДЛОЖЕНИЯ, БЕРИ ИЗ meta description",
  "image": "ПОЛНЫЙ URL ГЛАВНОЙ КАРТИНКИ ТУРА",
  "brand": {
    "@type": "Brand",
    "name": "SB Excursions"
  },
  "offers": {
    "@type": "Offer",
    "url": "ПОЛНЫЙ КАНОНИЧЕСКИЙ URL ЭТОЙ СТРАНИЦЫ",
    "price": "ЧИСЛО БЕЗ ЗНАКА ВАЛЮТЫ, например 69",
    "priceCurrency": "USD",
    "availability": "https://schema.org/InStock",
    "priceValidUntil": "2026-12-31"

</script>
```

## Проблема

Заголовки туров сделаны прилично, но **без цены**. Для коммерческих запросов цена
в заголовке — один из сильнейших драйверов кликабельности. Пример реального текущего:

```

```

Эта страница на позиции 6.4 и даёт 0 кликов при 18 показах.

## 2.1 Формула

```
[Что это] in/from Bali | [Конкретика] from $XX
```

Длина 50–60 символов. Слово Bali обязательно. Цену бери со страницы.

Примеры переделки:

```
БЫЛО:  Private Car with Driver in Bali | Flexible Daily Hire
СТАЛО: Private Car with Driver in Bali from $59 per Car

БЫЛО:  Sunset Cruise | SB Excursions
СТАЛО: Bali Sunset Dinner Cruise from $XX | Benoa Harbour
```

**Название компании из заголовка убирай** — оно съедает символы, бренд пока никто не ищет.
