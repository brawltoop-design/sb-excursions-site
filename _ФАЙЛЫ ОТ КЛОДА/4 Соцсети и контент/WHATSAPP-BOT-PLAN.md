# Python-бот для WhatsApp — план для SB Excursion

## Короткий ответ

**Да, бот сделать можно, и в твоём случае он почти бесплатный.**

Причина: Meta берёт деньги только за сообщения, которые бизнес пишет ПЕРВЫМ (реклама, рассылки). А когда клиент пишет тебе сам — открывается 24-часовое «сервисное окно», и все ответы внутри него **бесплатны**. Твои клиенты приходят с сайта и с SEO, то есть всегда пишут первыми. Значит Meta с тебя за переписку не возьмёт ничего.

Платить будешь только за мозги (LLM) и хостинг — это примерно **$10–20 в месяц** при твоих объёмах.

## Одно жёсткое правило, прежде чем начнём

**Только официальный WhatsApp Cloud API от Meta.**

Не `whatsapp-web.js`, не `Baileys`, не `pywhatkit`, не Selenium. Все они работают через подделку веб-клиента, WhatsApp это детектит, и результат ты уже видел — твой семидневный бан прилетел именно за это.

Разница критичная: сейчас у тебя ограничение на связанные устройства, и телефон работает. Второй раз банят **номер целиком и навсегда**. На твоём номере вся клиентская база, все переписки с поставщиками и все ссылки на сайте. Это не тот риск, который стоит $10 экономии.

# ЧТО НУЖНО ЗАВЕСТИ

### 1. Отдельный номер телефона ⚠️ САМОЕ ВАЖНОЕ

Номер, подключённый к Cloud API, **перестаёт работать в обычном приложении WhatsApp**. Твой `+62 853 336 850 20` подключать нельзя — ты потеряешь мобильный доступ ко всем текущим перепискам.

**Решение:** купи вторую индонезийскую симку (Telkomsel/XL, ~50–100k IDR) под бота.

Схема работы:
- **Старый номер** — ты лично, поставщики, водители, VIP-клиенты
- **Новый номер** — бот на сайте, первая линия. Когда клиент созрел — бот переводит на тебя

### 2. Meta Business аккаунт
`business.facebook.com` → создать бизнес-аккаунт → добавить WhatsApp Business Platform.

### 3. Верификация бизнеса
Нужны документы на компанию. Без верификации лимит — 250 уникальных новых контактов в сутки. Тебе этого хватит с огромным запасом, так что верификацию можно отложить и запуститься сразу.

### 4. Сервер с постоянным HTTPS-адресом
Webhook Meta должен куда-то стучаться. Варианты:
- **Railway.app** — проще всего, ~$5/мес, деплой из GitHub в два клика
- **Render.com** — есть бесплатный тариф, но засыпает при простое (для бота плохо)
- **VPS** (Hetzner / DigitalOcean) — ~$5/мес, полный контроль
- **Vercel** — у тебя там уже сайт, но serverless-функции неудобны для долгих диалогов

Рекомендую **Railway**.

### 5. API-ключ LLM
Anthropic (Claude) или OpenAI. Для такой задачи хватит самой дешёвой быстрой модели.

## `main.py`

```python
import os
import json
import httpx
from fastapi import FastAPI, Request, Response
from anthropic import Anthropic

app = FastAPI()
claude = Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

WA_TOKEN    = os.environ["WHATSAPP_TOKEN"]
PHONE_ID    = os.environ["WHATSAPP_PHONE_NUMBER_ID"]
VERIFY_TOKEN = os.environ["VERIFY_TOKEN"]   # придумай любую строку
OWNER_WA    = "6285333685020"               # твой личный номер для эскалации

# История диалогов. Для старта — в памяти.
# Когда пойдут реальные клиенты — перенеси в SQLite или Redis,
# иначе при рестарте сервера бот забудет все переписки.
conversations: dict[str, list] = {}

with open("knowledge.md", encoding="utf-8") as f:
    KNOWLEDGE = f.read()

with open("system_prompt.txt", encoding="utf-8") as f:
    SYSTEM_PROMPT = f.read().replace("{{KNOWLEDGE}}", KNOWLEDGE)


# --- Meta проверяет webhook при подключении ---
@app.get("/webhook")
async def verify(request: Request):
    p = request.query_params
    if p.get("hub.mode") == "subscribe" and p.get("hub.verify_token") == VERIFY_TOKEN:
        return Response(content=p.get("hub.challenge"), media_type="text/plain")
    return Response(status_code=403)


# --- Входящие сообщения ---
@app.post("/webhook")
async def incoming(request: Request):
    data = await request.json()
    try:
        value = data["entry"][0]["changes"][0]["value"]
        messages = value.get("messages")
        if not messages:
            return {"ok": True}          # статусы доставки — игнорируем

        msg = messages[0]
        if msg.get("type") != "text":
            await send(msg["from"],
                       "Thanks! I can only read text here — "
                       "could you write it out for me? 😊")
            return {"ok": True}

        sender = msg["from"]
        text   = msg["text"]["body"]
        name   = value.get("contacts", [{}])[0].get("profile", {}).get("name", "")

        reply = await think(sender, text, name)
        await send(sender, reply)

        # эскалация — бот сам ставит маркер, когда клиент созрел
        if "[HANDOFF]" in reply:
            await send(OWNER_WA,
                       f"🔥 ГОРЯЧИЙ ЛИД\n\n"
                       f"Имя: {name}\nНомер: +{sender}\n\n"
                       f"Последнее сообщение:\n{text}")
    except Exception as e:
        print("ERROR:", e)

    return {"ok": True}   # Meta всегда должна получить 200, иначе будет ретраить


async def think(sender: str, text: str, name: str) -> str:
    history = conversations.setdefault(sender, [])
    history.append({"role": "user", "content": text})
    history[:] = history[-20:]          # держим последние 20 реплик

    resp = claude.messages.create(
        model="claude-haiku-4-5",
        max_tokens=600,
        system=[{
            "type": "text",
            "text": SYSTEM_PROMPT + f"\n\nИмя клиента в WhatsApp: {name}",
            "cache_control": {"type": "ephemeral"},   # кэш = дешевле в разы
        }],
        messages=history,
    )
    answer = resp.content[0].text
    history.append({"role": "assistant", "content": answer})
    return answer


async def send(to: str, body: str):
    body = body.replace("[HANDOFF]", "").strip()
    url = f"https://graph.facebook.com/v21.0/{PHONE_ID}/messages"
    async with httpx.AsyncClient() as client:
        await client.post(
            url,
            headers={"Authorization": f"Bearer {WA_TOKEN}"},
            json={
                "messaging_product": "whatsapp",
                "to": to,
                "type": "text",
                "text": {"body": body[:4000]},
            },
        )
```

# ПОРЯДОК ЗАПУСКА — по неделям

### Неделя 1 — бесплатно, сегодня
Настрой быстрые ответы, приветствие и away-сообщение из файла `WHATSAPP-AUTO-MESSAGES.md`. Это даёт 70% эффекта за 0 рублей и без единой строчки кода. **Сделай это первым делом, даже если бота потом не будет.**

### Неделя 2 — инфраструктура
Вторая симка → Meta Business аккаунт → Cloud API → тестовый номер от Meta. Проверь, что webhook получает сообщения. Пока без LLM: пусть бот отвечает «Hello» на всё подряд.

### Неделя 3 — мозги, но осторожно
Подключаешь LLM. **Первый режим — только FAQ.** Бот отвечает про то, что включено, про трансфер, про оплату, про погоду. На любой вопрос о цене — сразу [HANDOFF] тебе. Так ты неделю смотришь логи и ловишь, где он врёт.

### Неделя 4 — цены
Когда соберёшь net-цены от поставщиков (те самые 61 контакт из трекера) — заполняешь таблицу цен, и бот начинает считать сам.

### Дальше
Уведомления в Telegram тебе о каждом горячем лиде, follow-up через сутки, если клиент замолчал, сохранение диалогов в базу.

# АЛЬТЕРНАТИВА БЕЗ КОДА

Если не хочешь держать сервер — есть готовые платформы поверх того же официального API: **Wati**, **Respond.io**, **Chatwoot** (open source, можно поставить у себя), **ManyChat**, **SleekFlow**. Примерно $30–80 в месяц, встроенный AI-агент, общий инбокс, готовые сценарии.

**Моё мнение:** тебе выгоднее свой код. Не из-за денег, а из-за контроля над промптом. У тебя специфический бизнес — перепродажа с маржой, где выдуманная цена это прямой убыток. В готовых платформах ты не залезешь так глубоко в правила поведения бота, как в своём `system_prompt.txt`.

# ЧЕСТНОЕ ПРЕДУПРЕЖДЕНИЕ

Бот — не замена тебе. Он закрывает три вещи:

1. **Ночь.** Твои клиенты в США и Британии пишут, когда на Бали 3 часа ночи. Сейчас эти лиды просто уходят.
2. **Первые 5 минут.** Скорость первого ответа — главный фактор конверсии в туризме. Ответ за 30 секунд против ответа через 6 часов это разница в разы.
3. **Одинаковые вопросы.** «Что включено», «есть ли трансфер», «как платить» — 60% всех сообщений.

Продавать дорогие приватные туры всё равно будешь ты. Бот твоя задача — довести клиента до момента, когда он готов говорить о деньгах, и не дать ему уйти, пока ты спишь.
