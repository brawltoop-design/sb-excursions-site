## Находки

### Тип schema переведён на китайский (Medium)
На page132181473-zh.html тип FAQPage превратился в 常见问题Page. Такого типа не существует — Google молча выбрасывает всю разметку страницы. JSON при этом валиден, ломается только смысл.

**Что делать:** Исправлено в этом аудите: имена типов schema.org добавлены в NEVER_TRANSLATE.

### Нет VideoObject у страницы с видео (Low)
На туре с китовой акулой появилось геройское видео, разметки нет.

**Что делать:** Добавить после того, как видео станет смотрибельным — сейчас это беззвучный фон без управления.
