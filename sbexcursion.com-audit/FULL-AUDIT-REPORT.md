# Аудит sbexcursion.com

**Оценка здоровья: 76 из 100**  ·  тип бизнеса: Local Service — туроператор, Бали

Проанализировано 1 456 страниц с диска, живые проверки на проде, данные Google PageSpeed и CrUX по ключу владельца, выгрузки Search Console и панели цитирования Copilot.

## Technical SEO — 85/100

**Что работает**

- 95% страниц в индексе (1328 из 1399)
- Каноникл на себя у всех 140 туровых страниц, ни одного noindex
- hreflang согласован: 0 ссылок на несуществующие страницы после раскатки немецкого
- robots.txt открыт для GPTBot, ClaudeBot, PerplexityBot и других AI-обходчиков

**Находки**

### Цепочка редиректов с голого домена  
`Medium`

http://sbexcursion.com → https://sbexcursion.com → https://www.sbexcursion.com — два прыжка. Каждый прыжок теряет часть веса ссылки и замедляет первый ответ.

**Что делать:** Настроить прямой редирект http://sbexcursion.com → https://www.sbexcursion.com одним шагом.

### Нет заголовков безопасности  
`Low`

Присутствует только strict-transport-security. Нет X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Content-Security-Policy.

**Что делать:** Добавить в vercel.json секцию headers. На ранжирование влияет слабо, но это гигиена и сигнал доверия.

### bali-review.html без canonical  
`Low`

Единственная содержательная страница сайта без тега canonical.

**Что делать:** Добавить самоссылающийся canonical.

- CLS 0 в лаборатории и 0,05 у живых пользователей (хорошо у 81%)

**Находки**

### LCP на мобильном 4,1 с — на границе «плохо»  
`Medium`

Лабораторный тест Lighthouse на мобильном: Performance 84, LCP 4,1 с при пороге «хорошо» 2,5 и «плохо» 4,0. На десктопе 0,9 с и Performance 99. Полевых данных по LCP в CrUX пока нет — трафика недостаточно, Google отдаёт только CLS и FCP, и оба хорошие.

**Что делать:** Заниматься, когда закроются более дорогие вещи. Lighthouse не указывает на конкретную причину, значит выигрыш даст только работа с геройской картинкой.

### ИСПРАВЛЕНО: прежняя оценка LCP 8 468 мс была ошибочной  
`Info`

В первой версии аудита LCP измерялся вручную через браузерную панель и дал 8 468 мс, что было отмечено как критическое. Замер оказался артефактом среды. Данные Google PageSpeed: 4,1 с на мобильном, 0,9 с на десктопе.

**Что делать:** Ручные замеры через панель для LCP не использовать — только PageSpeed и CrUX.

### У всех тегов img нет width/height  
`Low`

6 612 тегов без явных размеров. CLS при этом 0 в лаборатории и 0,05 в поле — сдвигов не происходит. Латентный риск, не активная проблема.

**Что делать:** Проставлять размеры в генераторе при случае.


## On-Page SEO — 58/100

**Что работает**

- H1 ровно один на 1 449 страницах из 1 456
- Дублей title всего 2, дублей description 1
- Английские заголовки переписаны «ответом вперёд», CTR за сутки вырос с 1,10% до 1,65%

**Находки**

### Сниппеты на языковых версиях обрезаются в выдаче  
`High`

Машинный перевод раздувает строку на 30-60%. Французский: 265 описаний из 266 длиннее лимита, максимум 301 знак. Русский 264 из 266, испанский 253 из 266, немецкий 98 из 101. Заголовки: fr 219/266, ru 199/266, es 189/266. Мы переписали английские заголовки так, чтобы ответ стоял в первой строке — в переводе он уезжает за обрез. Китайский чист: 28 из 266.

**Что делать:** Закрепить переводы title и description для страниц с наибольшими показами — сначала французские и русские, они дают 846 и 654 показа в неделю.

### На главной нет H1  
`High`

page128073236.html и все пять языковых версий главной не имеют H1 вообще. Первый заголовок сразу H2. Это самая важная страница сайта.

**Что делать:** Сделать H1 из главного заголовка героя.


## Content Quality — 72/100

**Что работает**

- Медиана гайда 2 512 слов, туровой страницы 1 522
- Указан автор с именем и должностью — сигнал E-E-A-T
- Блок бронирования теперь на 142 гайдах из 148 (было 21)

**Находки**

### Статьи-спутники туров дублируют друг друга на две пятых  
`High`

У каждого тура три статьи: why-book, travel-guide, tour-schedule. Сравнение тел без сайдбара и общих блоков: travel-guide против why-book пересекаются на 49-51% шестисловных фраз, в среднем по всем парам 39,8%. Таких страниц около 420. Это профиль, при котором Google отвечает «просканирована, не проиндексирована» — и таких у вас 22.

**Что делать:** Слить why-book в travel-guide с редиректами 301: минус ~140 почти дублирующих страниц, вес переходит выжившим.

### Шесть легаси-гайдов вне генератора  
`Low`

bali-canggu-beaches-guide, gili-islands-day-trip-from-bali и ещё четыре живут отдельными HTML. Они не получают ни блока бронирования, ни новых языков.

**Что делать:** Перенести в JOURNAL_SEO_GUIDES.

**Находки**

### Тип schema переведён на китайский  
`Medium`

На page132181473-zh.html тип FAQPage превратился в 常见问题Page. Такого типа не существует — Google молча выбрасывает всю разметку страницы. JSON при этом валиден, ломается только смысл.

**Что делать:** Исправлено в этом аудите: имена типов schema.org добавлены в NEVER_TRANSLATE.

### Нет VideoObject у страницы с видео  
`Low`

На туре с китовой акулой появилось геройское видео, разметки нет.

**Что делать:** Добавить после того, как видео станет смотрибельным — сейчас это беззвучный фон без управления.
